# NDS Cheat CRC

NDS 롬과 치트 파일을 선택하면, 해당 롬의 치트용 게임 식별값에 맞게 **R4 DAT·XML** 파일을 변경하고 자동 다운로드하는 웹 도구입니다.

별도 서버·패키지 설치·빌드 없이 **GitHub Pages**에서 작동합니다. 밝은 화면·어두운 화면, PC·모바일을 지원합니다. 파일 선택은 모든 화면에서 위아래로 배치되며, PC에서는 최대 너비를 유지하고 모바일에서는 화면 폭에 맞춰 줄어듭니다.

## 사용 방법

1. 소스 파일에서 `.nds` 롬을 선택합니다.
2. 치트 파일에서 `.dat` 또는 `.xml`을 선택합니다.
3. 여러 후보가 있으면 같은 게임에 해당하는 항목을 선택합니다. 같은 게임 코드의 후보가 하나뿐이면 자동 선택됩니다.
4. **치트 파일 변환 · 다운로드**를 누릅니다.
5. 생성된 파일을 에뮬레이터나 기기의 치트 데이터베이스로 다시 가져옵니다.

자동 다운로드가 제한되는 브라우저에서는 결과 영역의 **다시 다운로드**를 누르세요. R4·TWiLight Menu++에서 `usrcheat.dat` 이름이 필요하다면 다운로드한 파일 이름을 바꿔 사용합니다.

## GitHub Pages에 올리기 — 빌드 불필요

1. GitHub에서 Public 저장소를 만듭니다. 예: `nds-cheat-crc`.
2. **이 폴더 안의 파일**을 저장소 최상위에 올립니다. `index.html`, `core.js`, `app.js`, `styles.css`, `favicon.svg`가 같은 위치에 있어야 합니다. 폴더 전체가 한 단계 더 중첩되지 않게 올리세요.
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로 선택합니다.
4. Branch를 **main**, 폴더를 **/(root)**로 선택하고 **Save**를 누릅니다.
5. 게시가 끝나면 `https://계정이름.github.io/저장소이름/`에서 이용합니다. 실제 주소는 Pages 화면의 **Visit site**로 확인합니다.

`test/`, `scripts/`, 문서도 함께 올려도 됩니다. `.nojekyll`은 정적 파일을 그대로 제공하기 위한 빈 파일입니다.

[GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

## 로컬 미리보기·검증

`index.html`을 브라우저에서 직접 열어도 작동합니다.

Node.js 18 이상이 있으면 설치 없이 다음 명령을 사용할 수 있습니다.

```sh
npm test
npm run preview
```

미리보기 주소는 `http://127.0.0.1:8767`입니다. 런타임·개발 패키지 의존성은 없습니다.

## 변경 범위

- **NDS:** 맨 앞 512바이트만 읽습니다. 롬은 변경하거나 출력하지 않습니다.
- **XML:** 선택한 `<game>`의 `<gameid>` 내용만 변경합니다. 나머지 문자열, 코드·설명·폴더·순서·줄바꿈·인코딩·BOM을 유지합니다.
- **DAT:** 선택한 게임의 인덱스에서 게임 코드 4바이트·CRC 4바이트만 변경합니다. 데이터 위치·코드 본문·다른 게임 데이터는 모두 유지합니다.
- **중복 방지:** 같은 대상 식별값이 다른 게임 항목에 이미 있으면 중복 변환을 막습니다. 그 항목을 선택하면 원본 그대로 다운로드할 수 있습니다.
- **파일 크기:** 게임 항목을 복제하지 않으므로 DAT 크기는 동일하고, XML은 바뀐 gameid의 글자 수 차이만 반영됩니다.

## 지원 형식

- Nintendo DS `.nds` 게임 코드 4자 및 512바이트 헤더.
- 암호화되지 않은 **R4 `usrcheat.dat`** 형식. 모든 종류의 `.dat` 또는 암호화된 `cheat.dat`를 뜻하지 않습니다.
- **codelist XML**, UTF-8 / UTF-16 LE·BE. 다른 문자 인코딩은 UTF-8로 저장한 뒤 사용하세요.
- 치트 파일은 최대 64MiB까지 지원합니다. ZIP은 먼저 압축을 풀어야 합니다.

이 도구는 게임 식별값을 연결합니다. 언어·게임 버전이나 롬 패치로 코드 주소가 달라진 치트까지 자동 변환하지는 않습니다.

## 개인정보·보안

파일을 서버로 전송하지 않습니다. 파일 내용은 브라우저 메모리에서 처리하고 Blob 다운로드로 저장합니다. 분석 도구·광고·CDN·외부 글꼴·계정·클라우드 저장소를 사용하지 않습니다. 테마 선택만 브라우저 설정에 보관합니다. XML의 DTD·외부 엔티티는 처리하지 않습니다.

GitHub Pages에는 웹앱 소스만 올리세요. 롬·BIOS·세이브·치트 데이터베이스는 배포 파일에 포함하지 않았습니다.

## 코드 구조

- `index.html`: 접근성 레이블, 파일 입력·게임 선택·결과 UI
- `styles.css`: 반응형 디자인 및 밝은/어두운 테마
- `core.js`: JAMCRC·NDS 헤더·XML·R4 DAT 파싱과 식별값 변경
- `app.js`: 로컬 파일 읽기·선택·다운로드
- `test/core.test.cjs`: 외부 파일 없이 실행되는 회귀 검사
- `scripts/serve.cjs`: 로컬 정적 미리보기

직접 작성한 코드의 라이선스는 MIT입니다. 파일 형식 분석과 계산 기준은 [FILE_FORMATS.md](./FILE_FORMATS.md)에 정리했습니다.
